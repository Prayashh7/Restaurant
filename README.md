Website for Restaurants :
Live : https://restaurant077.netlify.app/

A modern and responsive restaurant website designed to provide customers with a smooth, engaging, and convenient online experience. The website showcases the restaurant, menu, services, and ordering options through a clean, attractive, and user-friendly interface.


Features
🏠 Modern and responsive homepage
🍽️ Restaurant menu and food showcase
🛒 Online food ordering
💵 Cash on Delivery option
💬 WhatsApp ordering integration
📅 Visit request system
🔐 Secure admin dashboard
📱 Mobile-friendly responsive design
🎨 Modern and visually appealing UI
⚡ Fast and smooth user experience
🌐 Full-stack restaurant platform

Technologies Used
React.js – Frontend development
JavaScript – Functionality and interactions
Node.js & Express.js – Backend development
PostgreSQL – Database management
CSS3 – Styling and responsive design
Git & GitHub – Version control

Purpose
This project was developed to create a complete digital platform for a restaurant, combining a modern customer experience with practical restaurant management features. It focuses on responsive design, convenient ordering, secure administration, and real-world usability.
